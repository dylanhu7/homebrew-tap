# Homebrew tap

[Homebrew](https://brew.sh) casks for my Mac apps.

| App | Install |
| --- | --- |
| [Tandem](https://github.com/dylanhu7/tandem): record several windows at once, each to its own movie file | `brew install --cask dylanhu7/tap/tandem` |

Use the full name shown above. Homebrew's main catalogue has an unrelated cask
that is also called `tandem`, and the short name installs that one.
